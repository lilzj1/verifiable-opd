# 完整教师矩阵登记 v1

2026-09-26 05:30 UTC 前登记；执行前冻结，不是正式训练许可。

## 目的和样本

三模型：固定MixSFT、Math RL、IF RL，同一公开版本与RoPE兼容overlay，不更新权重。
使用冻结dev每域全部64题，各模型128响应，合计384。前16题与长度诊断重合，必须报告重合，不称作384道独立题。

## 共同解码

- max_prompt=2048，max_response=8192，max_model_len=10241；不扩大到32K。
- dtype=float16，三模型一致；实际教师评分数值已验证该精度，学生训练仍BF16。
- temperature=.6、top_p=.95、top_k=20、seed17，每题一次。采样设置取固定官方本地评测示例，非论文严格复现声明。
- 使用现有模板、原始token ID、固定final提取/规则判分器；不追加正确答案，不补结束标签。
- 训练候选temperature=1，评测采样不反向冒充训练配置。

## 预登记判断

1. 样本集合/响应完整性、checker错误、数值/推理错误是硬条件；缺响应不记为模型答错后继续。
2. 分别报告每域正确率、模型间逐题配对点差与95% question bootstrap区间、截断率、真实token量和墙钟。
3. 候选准入：两位教师在各自域对MixSFT均有正点差；同时检查Math教师在Math对IF教师、IF教师在IF对Math教师是否有正点差，确认专项互补。CI含0必须如实说明，不宣称显著。
4. 只有准入满足，才进入小规模S2/S3更新与恢复/profile；该矩阵不能自动批准50次正式训练。
5. 若点差或互补证据不足，不无限换题/调门槛；先保留结果并报告阻塞。仅样本不确定时才考虑方案既定的每域128上限，但当前只授权执行本64矩阵，不自动补样。
6. 不以教师比学生高一点掩盖数学大量截断。即使点差通过，也必须按profile报告8192在线采样、教师评分、反向和评测成本，再冻结预算。

## 数据限制

公开模型曾否见过题目未知；dev含一条段落约束元数据矛盾。保留全体dev作为主口径，附标记，不事后剔除以抬高得分。原判分器对非法段落号会重新采样；本地固定random seed17，但这不使原文字矛盾消失。

## 执行/停止

GPU1学生、GPU2数学、GPU3指令，GPU4诊断结束后空闲；不碰其他卡。每模型脚本timeout=2小时，完整或失败均落退出码。新独立目录，不覆盖旧probe；失败不接力训练。
